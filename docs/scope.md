# Stage 1の範囲と検証の限界

基準はCCM v0.1 Draft 6と、ユーザーが指定したP0・P1項目です。P0の公開整合性を保ったまま、P1の保守運用を追加します。

| 単位 | 実装 |
|---|---|
| P0 公開スナップショット | 承認した作品・タイトル方式・ジャンル・キューを下書きから分離し、同じ版のJSON本文を固定する |
| P0 API更新・削除 | 更新・削除と公開版・公開要求を原子的に更新する。APIエラーを動画の取得不能と混同しない |
| P0 公開結果・版確認 | 両JSONの照合結果をD1へ保存し、公開直前に現在の版とロックを再確認する |
| P1 公開対象の限定 | 新しい `public-artifact/` に2つのJSONだけを作る。余分なファイル、リンク、作成後の本文変更を拒否する |
| P1 定期保守・復旧 | Actionsが全審査状態の作品を再取得・削除判定する。旧実行の終了根拠が揃った場合だけ公開ロックを復旧する |
| P1 結合試験 | URL候補登録→再取得→人による審査→公開承認→取得不能確認→削除→公開結果記録を合成データで検証する |

初回移行時の承認済み構成はP1でも引き継ぎます。公開本文が変わるたびに旧スナップショット本文を除去し、リビジョン番号は再利用しません。削除監査と復旧履歴へ動画ID・URL・タイトルやAPI応答本文をコピーしません。

## 今回の対象外

- キーワード、チャンネル、再生リストによる新着自動探索。P1の入口は明示的なURL単体登録です。
- P2の過去作品探索、高速審査UI。
- 人の採否判断・公開構成承認の自動化、根拠なしの強制ロック解除。
- サイト全体の非常停止、VRChat連携の実機保証、全サービスの無料枠・課金管理。
- 長期間の無人運転の実証。本番切替と観測期間中の実行結果は別途記録します。

## 保証の境界

**D1更新とPages公開は別の処理です。** D1の削除が完了しても、公開URLの両本文が一致し、結果がD1へ保存されるまで公開完了とはしません。認可直後に最新版が変わった場合も、新しい版の公開要求は残ります。

**固定URLの2ファイルには全クライアントでの同時切替保証がありません。** キャッシュや取得時刻で版が混在し得ます。検証地点で両方が一致したことと、全利用者の同時整合性を区別します。

**復旧は終了根拠が得られるケースに限定します。** GitHubの該当実行・試行・jobが完了し、Pages stepが成功または未実行と確認できた場合に再公開へ進めます。timeout・cancelled・failure等でPages側の終了が不明ならロックを維持します。時間経過だけでは解除しません。

**定期実行時刻は保証されません。** GitHub Actionsは高負荷時に遅延・欠落することがあり、公開リポジトリでは60日間活動がないとscheduled workflowが無効化されます。[GitHub公式：schedule](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)

**保守集計は受信できた応答に基づきます。** D1の更新後に応答が失われると、処理件数とrunの集計値が一致しない場合があります。`refreshRequests` は送信試行数であり、YouTubeのクォータ確定値ではありません。D1内の取得時刻を進捗として次回に引き継ぎます。

**期限管理は全コピーの即時消去を証明しません。** 通常DBと旧スナップショットの除去は、D1 Time Travel、外部キャッシュ、既存VRChatインスタンスの消去とは異なります。30日と72時間の設定はサービス全体の消去保証ではありません。[D1 Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/)

**D1への直接書込みはAPIの整合性保証外です。** 世代検証、公開要求、監査を迂回するため、通常運用はWorker APIに統一します。

YouTubeデータの保持・再提供やVRChat側のURL受渡しは別途確認が必要です。技術試験の成功だけで上映システム全体の適合性確認済みとはしません。[YouTube Developer Policies](https://developers.google.com/youtube/terms/developer-policies)、[VRChat External URLs](https://creators.vrchat.com/worlds/udon/external-urls/)
